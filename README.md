# Word Scramble

A mini word game. Unscramble the letters before the 60-second timer runs out.

Open `index.html` in any browser to play — no install needed.

- Type the word or click letter tiles, then press **Enter** / **Check**
- Correct answers score points equal to the word length and add 3 seconds
- 3+ correct in a row gives a +2 streak bonus
- **Hint** reveals the next letter (−1 point), **Shuffle** remixes the tiles, **Skip** shows the answer
- Your best score is saved in the browser
